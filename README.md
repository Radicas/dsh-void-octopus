# 虚空八爪鱼（dsh-void-octopus）

一只**透明悬浮**在 DSH Web 界面上的 three.js 虚空八爪鱼。没有方框、没有背景、没有标题栏——它直接漂在对话上方，暗部通过 `mix-blend-mode: screen` 融进页面，只有眼睛、边缘光和触手真正发亮。

它不读你的工作内容，只跟着工作节奏呼吸：空闲时缓慢漂浮，思考时更专注，生成时发亮，跑工具时动作更快、能量更高。

## 当前形态

- 400px 透明 WebGL 层在视口内**缓慢漂浮**，从右下角入场，沿双正弦路径巡游；直接挂在 `document.body` 上（绕开 shell.overlay 的层级与混合上下文），`pointer-events: none`，不挡任何点击。
- 打字/点击时自动淡到 20%，停手 2.6 秒后回到 80%，不抢阅读。
- 窗口、面板、收起按钮全部移除；要关闭它，去 Settings → Plugins 禁用，或：
  ```
  plugin_manager remove_bundle dsh-void-octopus
  ```
- 状态来源只有 `useSessionStatus` 的 `running` 和 `useChat` 的 `runningCalls` / 流式文本长度，不读语义。
- 点击不会脉冲（避免误触界面），鼠标移动会让它轻微转头。

## 安装

```
plugin_manager install_bundle github:Radicas/dsh-void-octopus
```

也可以下载 GitHub Releases 里的 `dsh-void-octopus-0.9.9.tgz`，用绝对路径安装：

```
plugin_manager install_bundle /绝对路径/dsh-plugins/dsh-void-octopus/dsh-void-octopus-0.9.9.tgz
```

也可以直接指向目录。装完刷新页面；它从右下角入场，在视口内缓慢巡游，随会话状态变化。

## 开发

```bash
npm install --cache ./.npm-cache
npm run build:demo   # 独立 demo：demo/bundle.js
npm run serve:demo   # http://127.0.0.1:4173
npm run build:client # 生成可安装的 client.js
npm run selfcheck    # 发布门禁：loader 包装 / React 外置 / three 内联
```

`demo/` 是带背景的场景实验台；`test/harness.html` 用假 `__ModuleLoader__` + 真实 React 验证打包后的 `client.js`（不启动 DSH）。插件视图本身已无 UI 外壳，所以没有可点的收起/展开控件，这是有意为之。

## 身体连接（0.6.0）

- 触手第 0 个控制点移到 mantle 内部，让管子从身体里“长出来”，而不是在底边被截断。
- mantle 剖面补了下半球的封口，不再是一个开口的碗。
- 新增 7 片 instances 的 **webbing membrane**：相邻触手根部之间用一层加法混合的发光薄膜连接，缝隙被补上；t=0.02–0.34 范围内随触手实时形变。
- 原有的 skirt glow 环保留，作为连接处的生物光。

## 生命感升级（0.5.0）

- **眼睛**改成程序化 shader：虹膜、竖瞳、瞳孔缩放、高光；加入 saccade（不定时扫视）、上下眼睑闭合、偶尔双眨和慢眨，不再靠整体缩放眼睛。
- **动作**加入 7–16 秒一次的喷水脉冲（mantle 收缩 + 触手外张 + 身体轻抬）、沿触手传播的行波、偶发触手尖抽动；提高了 idle 速度，弹簧更紧，身体会缓慢侧倾。
- **皮肤**加入体内星云（缓慢流动的低频噪声）、更稀疏的硬星点、斑驳和细褶、边缘次表面散射。

## 0.9.9 真实游泳姿态

- 参考真实章鱼：主要靠**喷水推进**（mantle 收缩、siphon 喷水），游泳时头在前、**触手向后拖成流线**；不是鱼鳍式划水。
- 提高划水/拖尾幅度：触手在移动时收拢、向后拖，尖端位移更大；喷水瞬间拖尾加强。
- 悬浮层移动速度会随喷水脉冲**加速/滑行**，形成 burst-glide，而不是匀速平移。
- 保留部分物种的“触手张开滑翔”作为慢速姿态。

## 0.9.8 游泳动作

- 悬浮层的移动速度/方向会实时传给生物：它会被移动方向带着**侧倾/俯仰**。
- 触手加入游泳 stroke：沿整条曲线传播的行波，移动时幅度更大；尖端会向运动反方向**拖尾**。
- 移动时会缩短喷水间隔，形成“喷一下、滑行、再喷”的节奏。
- 不动或停在原地时动作自动减弱，回到缓慢漂浮。

## 0.9.7 性能优化

- 环境插件渲染分辨率从 100% 降到 **70%**（400px 层实际 280px）后由 CSS 放大，像素量减半。
- 帧率上限从 30 降到 **24fps**；页面隐藏暂停不变。
- SDF 步进上限 38 → **30**，步长系数 0.92 → 0.985；法线从 6 次采样降到 **4 次**。
- 插件模式关闭 `preserveDrawingBuffer`，减少每帧缓冲拷贝；演示模式保留以便截图。

## 0.9.6 连续曲线触手

- 每条触手的骨架改成一条 **cubic Bezier 曲线**，采样 8 个点、7 个 tapered capsule；不再是几段直管拼接。
- 关节用更小的 smooth-min（0.08）过渡，半径沿曲线连续收细；视觉上没有“骨头”折点。
- 触手保持外扩 + 末端上翻，行波沿曲线传播；根部蹼膜保留。

## 0.9.5 触手朝外朝上

- 触手改成 U 形：从根部向外下方伸出，再在末端**向外、向上翻卷**，不再全部朝内钩。
- 尖端用切向偏移做侧向卷曲，而不是向身体中心收拢。
- 8 条触手长度/高度有差异，不是同一个模子；行波和吸盘保留。

## 0.9.4 触手曲线

- 触手从 4 点/3 段提到 **6 点/5 段**，控制点沿“外扩 → 下垂 → 尖端内卷”的 S 曲线排布，不再像直腿。
- 每段半径从 0.20 → 0.02 连续收细，尖端是圆头而不是爪尖。
- 加了一条沿触手传播的行波（相位逐段滞后），吸盘提示更明显；根部蹼膜略微加大。
- 行波、卷曲、拉伸仍由 idle 自主动作驱动。

## 0.9.3 默认状态自主动作

- idle 时会自己决定做点什么：随机间隔 2.5–6 秒触发一次，动作包括
  - 转头看别处（`look`）；
  - 随机一条触手卷起来再放回去（`arm`）；
  - 8 条触手一起伸展/舒展（`stretch`）；
  - 喷水推进（`jet`，身体收缩 + 触手外张 + 轻抬）；
  - 眨眼/双眨（`blink`）。
- 动作之间用阻尼过渡，不会突然跳变；正在生成/跑工具时不会触发新的自主动作。

## 0.9.2 对称眼睛

- 眼睛改成**前外侧 45°**朝向，左右使用镜像的切线基，高光/虹膜严格对称。
- 去掉之前过大的青色眼晕，避免两只眼睛糊成两团；保留暗眼窝和琥珀虹膜。
- 眼睛更大、更凸出；默认视角改成接近正面，两只眼睛同时可见。

## 0.9.1 头部重做

- 头从单个圆球改成**两段结构**：上方圆润的 mantle 囊 + 下方较窄的头部，中间自然收颈。
- 两侧加**隆起的眼窝**，眼睛嵌在眼窝里，不再是贴在球面上的装饰。
- 补了**siphon**（带内孔的漏斗）和头部与触手之间的**短蹼膜**。
- 增加顶部/侧向主光，头部有明确的高光面和暗面；渲染分辨率提到 100%，边缘更干净。

## 0.9.0 头部与眼睛

- mantle 从圆球改成 **带尖顶的卵形**，叠加 hood 和 siphon，轮廓更像真正的章鱼头。
- 眼睛从正面卡通大眼改成 **头两侧的琥珀色眼睛**：水平瞳孔、虹膜纹理、眼睑、小角膜高光，不再是大白高光 + 竖瞳。
- 皮肤加入 chromatophore 色斑、papillae 粗糙颗粒和湿滑高光；身体保持深蓝紫，不再发白。
- 保持一体 SDF、3/4 侧漂浮、喷水脉冲。

## 0.8.0 观感修正

- 去掉白色高光主导的“鬼火”观感：身体改成深蓝紫基底，只保留青色/紫色边缘光和星点，高光不再把整只生物洗白。
- 增加 eye halo、触手双排吸盘提示、触手尖端发光；眼睛更大更靠外。
- 加入 7–14 秒一次的喷水脉冲（身体收缩 + 触手外张）和缓慢侧倾/呼吸，减少“半死不活”的静态感。
- 默认改成 3/4 侧漂浮姿态，而不是正面圆球。

## 一体 SDF（0.7.0）

- 不再使用“球体 + 8 根独立 Tube”：整只生物是一个 **signed distance field**，身体、8 条触手、根部蹼膜、眼睛全部在同一个场里用 smooth union 融合。
- 触手由 CPU 每帧计算 8×4 个控制点，传入 fragment shader；着色器里用 24 个 tapered capsule 求距离，所以没有网格接缝、没有“贴上去”的根部。
- 眼睛也参与 SDF，是嵌在 mantle 里的球体；虹膜、竖瞳、眼睑、高光、saccade 全部在同一个 fragment shader 里完成。
- 遮蔽、边缘光、星点、斑驳、次表面散射是逐像素计算的；通过屏幕混合只加光，不出现黑框。
- 400px 层以 0.8 分辨率渲染并上采样，30fps；没有外部模型/贴图，全部程序化。

## 造型升级（0.4.0）

- 触手从 46×8 提到 **64 环 × 12 边**，用 **parallel transport 标架** 代替 Frenet，消除扭转和折面。
- 曲线改为 **centripetal Catmull-Rom**，9 个控制点，减少过冲；触手有弹簧式二次运动，惯性/阻尼让它跟手。
- 每条触手增加 **两排 9 个实例化吸盘**，沿下侧排列，共 144 个，只用一个 InstancedMesh。
- 头部皮肤加入低频斑驳、细褶和边缘次表面散射；触手改为连续行波，减少高频噪点。
- 仍然保持 30fps 上限和全程序化资产。

## 实现要点

- **three.js 打包进 `client.js`**（约 490 KiB min），React 保持 `require('react')` 外置。
- **透明合成**：renderer `alpha: true` + 场景不铺背景 + CSS `mix-blend-mode: screen`。深色身体在屏幕上几乎不增光，只有高光、眼睛、触手和 bloom 可见，所以不会出现一个黑色方框。
- **程序化 SDF**：整只生物是一个 signed distance field；每帧由 CPU 计算 8 条触手 × 8 个 Bezier 控制点，shader 里用 56 个 tapered capsule 与平滑并集融合身体和蹼膜，眼睛也参与同一 SDF 场；没有任何 GLTF/GLB（插件资源路由只允许图片）。
- **性能**：DPR 1–1.25、环境层 24fps / 0.7 渲染比例、页面隐藏暂停、`prefers-reduced-motion` 降速、WebGL 失败静默降级；没有窗口可收起，卸载即 dispose。
- **升级安全**：通过 `shell.overlay` 注册组件，但把 fixed 层挂到 `document.body`，不覆写宿主类名。

## 已知限制与下一步

- 位置不持久化，刷新后从右下角重新入场；不能拖拽；下一步做拖拽 + 位置记忆。
- 浅色主题下 `screen` 混合会偏弱，目前按深色 UI 调校。
- 只有一只生物；下一步可以做第二套配色/第二只虚空生物。
